#  Smart_ChainFund  
### Subject: Data Security and Blockchain  
Course: Master's in Data Science (2nd Year)

---

##  Project Overview

Smart_ChainFund is a decentralized crowdfunding platform that combines Blockchain, Data Security, and Machine Learning.

This project shows how smart contracts remove middlemen and how machine learning helps users predict campaign success before launching.

---

##  Objectives

- Build a secure crowdfunding system using blockchain  
- Ensure transparency and immutability  
- Integrate machine learning for prediction  
- Provide smart suggestions to users  

---

##  Security Features

- Non-Custodial Wallets (users control funds)  
- Client-Side Transaction Signing  
- Secure Key Generation using ECC  
- Environment variables for sensitive data  

---

##  Machine Learning Integration

The system predicts campaign success before publishing.

### Features:
- Success Probability (0–100%)  
- Risk Level (Low / Medium / High)  
- Confidence Score  
- Smart Suggestions  

###  Model:
- Random Forest (better than logistic regression)
